# Yedupa Uygulamalar

Bu depo temel olarak web tabanlı uygulama örnekleri içerir.

## Diyet Takip Uygulaması

`diet.html` dosyası modern görünümlü bir diyet takip arayüzü sunar. Kullanıcılar yalnızca yemeğin adını ve miktarını yazarak kalori ile makro değerlerini otomatik hesaplar. Sayfadaki sekmeler aracılığıyla öğün listesi ve haftalık kalori grafiği arasında geçiş yapılabilir.

Uygulamayı çalıştırmak için bir tarayıcıda `diet.html` dosyasını açmanız yeterlidir.
