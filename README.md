# Yedupa Uygulamalar

Bu depo temel olarak web tabanlı uygulama örnekleri içerir.

## Diyet Takip Uygulaması

`diet.html` dosyası gelişmiş detaylara sahip basit bir diyet takip arayüzü sunar. Kullanıcılar yemeğin adını ve miktarını girerek kalori ile makro değerlerini otomatik olarak hesaplayabilir, günlük öğünlerini ekleyip toplam kalorilerini takip edebilir ve haftalık kalori grafiğini inceleyebilirler.

Uygulamayı çalıştırmak için bir tarayıcıda `diet.html` dosyasını açmanız yeterlidir.
